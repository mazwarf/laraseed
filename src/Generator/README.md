# Generator

Folder ini akan berisi kelas-kelas Writer yang merender stub dan menulis file
hasil generate ke disk.

## Rencana Isi (Modul 5 & 6)

- `FactoryGenerator.php`  — Merender stub factory dan menulis ke `database/factories/`.
- `SeederGenerator.php`   — Merender stub seeder dan menulis ke `database/seeders/`.
- `PolicyGenerator.php`   — Merender stub policy dan menulis ke `app/Policies/`.
